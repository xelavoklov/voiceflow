# VoiceFlow

Плавающая кнопка диктовки для Ubuntu (GNOME/Wayland), аналог Wispr Flow.
Клик по кнопке — запись, второй клик — распознавание локальной моделью
[faster-whisper](https://github.com/SYSTRAN/faster-whisper) и вставка текста туда, где стоит курсор.

## Как работает
- Окно GTK3 через XWayland: всегда поверх, не берёт фокус, поэтому вставка попадает в нужное приложение.
- Запись — `pw-record` (16 кГц, моно).
- Распознавание — отдельный процесс `worker.py` в своём venv, модель держится в памяти (GPU, иначе CPU).
- Вставка — `wl-copy` и виртуальная клавиатура через `/dev/uinput` (Ctrl+V). Прежний буфер обмена восстанавливается.

## Требования
`python3-gi` + GTK 3, `pipewire` (`pw-record`), `wl-clipboard`, `uv`, доступ на запись в `/dev/uinput`.

## Установка и запуск
```
./install.sh          # или ./install.sh --cuda, если нужны CUDA-библиотеки из pip
./run.sh
```
Автозапуск: скопировать `voiceflow.desktop` в `~/.config/autostart/`.

## Использование
- Левая кнопка: запись / стоп. Перетаскивание — переместить кнопку.
- Правая кнопка: модель, язык, режим вставки (Ctrl+V или Ctrl+Shift+V для терминалов), выход.
- Настройки: `~/.config/voiceflow/config.json`.
